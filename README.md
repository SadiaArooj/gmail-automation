
# Gmail Automation

A Python-based automation project that aims to
connect Gmail with Google Sheets.

## Project Goals

- Connect Python with Gmail API.
- Read emails automatically.
- Extract email information.
- Store email data in Google Sheets.
- Avoid duplicate entries.

## Technologies

- Python
- Gmail API
- Google Sheets API
- Git and GitHub
